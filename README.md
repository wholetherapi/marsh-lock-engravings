# Marsh Lock Engravings — digitisation package

Digitisation package for the Marsh Lock Engravings (FMA-MLE-1876), released on 2025-11-04.

## Contents

- `manifests/plate-list.csv` — plate-level inventory of the 94 engravings
- `metadata/engravings.csv` — descriptive metadata transcribed from the commissioners' minute book
- `scripts/ocr_cleanup.py` — post-processing for the OCR layer on the plate versos
- `docs/provenance.md` — provenance notes from the engineer's office to the archive

## Access

Open access. Plate images are served as access derivatives; preservation files remain on the archive store.

## Version

Package version 1.0 — last content update 2025-11-04.
